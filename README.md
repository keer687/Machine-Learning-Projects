# 🚀 Machine Learning Predictive Modeling Projects

This repository contains three end-to-end Machine Learning projects completed as part of my **Machine Learning & Data Science Internship**. These projects demonstrate data preprocessing, exploratory data analysis (EDA), feature engineering, model development, evaluation, and visualization using Python and Scikit-learn.

---

## 📌 Project 1: Multi-Class Classification (Iris Dataset)

### Objective
Build and compare classification models to predict Iris flower species.

### Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

### Algorithms
- Logistic Regression
- Decision Tree Classifier

### Key Features
- Data preprocessing
- Feature scaling using StandardScaler
- Train-test split
- Model evaluation
- Confusion Matrix
- Classification Report
- Accuracy comparison
